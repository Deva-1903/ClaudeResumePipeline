Position: AI Software Engineering Intern

- Prototype, test, refine, and ship features rapidly.

Requirements:
- Bachelor's degree in Computer Science, Software Engineering, Data Science, or a related field.
- Must be a recent graduate. Must be local. Must commit to a full-time, three-month internship.

- Must be comfortable working independently with minimal guidance.
- Must be able to self-teach, experiment, and solve problems without an internal software-engineering team.

Preferred:
- Python. Streamlit or web-app development. APIs, JSON, and Python data manipulation. OpenAI API or other LLM tools. Manufacturing, ERP, MRP, or supply-chain systems.
