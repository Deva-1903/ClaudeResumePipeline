About ePlannerPro
ePlannerPro is a comprehensive platform enabling exhibitors to streamline meeting management at trade shows and conferences. We're transforming professional event and project management through intuitive planning tools — and we're building the next generation of that platform right here in Atlanta.

Role Overview
This role targets recent graduates or early-career professionals interested in building real-world applications while developing technical skills in a collaborative setting. You'll have the potential to contribute to an AI Agentic workflow platform for conference and trade show planners.

Key Responsibilities
Assist in developing, testing, and maintaining software products
Collaborate with senior developers and product teams on new features
Participate in weekly stand-ups, sprint planning, and code reviews
Write clean, readable code and contribute to documentation
Learn and apply modern software engineering best practices
Troubleshoot issues and fix bugs as they arise

Required Qualifications
Pursuing or completed Bachelor's degree in Computer Science, Software Engineering, or related field
Understanding of basic software development principles and version control
Willingness to learn new technologies and frameworks
Strong communication and teamwork skills
Passion for building user-friendly applications

Nice-to-Have Skills
Web and mobile development frameworks (React, Node.js, Django)
Database experience (SQL or NoSQL)
