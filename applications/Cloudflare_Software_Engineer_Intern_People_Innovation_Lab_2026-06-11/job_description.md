# Cloudflare — Software Engineer Intern, People Innovation Lab

Location: Austin. Internship Duration: 12 weeks. Schedule: Full-time (3 days/week in office).

## About Us
Cloudflare runs one of the world's largest networks, powering millions of websites and Internet properties. Protects and accelerates Internet applications without hardware/software/code changes. Culture built on iteration, leveraging AI to ship faster, sharing every improvement across the team. Values curiosity over bureaucracy and AI as a partner in solving tough problems. Looking for builders who spot "normalized" problems and have AI-native curiosity to create solutions.

## About the Role
Join the People Innovation Lab to rapidly build and deploy internal enterprise applications and tooling for the Cloudflare People & Places organization, focused on making work smarter.
- Build production features in a sprint-based team.
- Work guided by the IT Customer Zero team and deployed on Cloudflare infrastructure.
- Strong fundamentals and fast ramp-up ability are essential.

## What You'll Build & Do
- Build and ship full-stack features, clean production code, and integrations for internal tools.
- Write and review code, work in sprints (managing tickets/blockers), coordinate with the other intern.
- Effectively use AI-assisted coding tools.
- Demo working products to leadership.

## Requirements & Qualifications
Minimum:
- Pursuing CS, Software Engineering, or related degree (or equivalent experience).
- Ability to build and demonstrate a working web application.
- Proficient in JavaScript/TypeScript and comfortable with one back-end language/framework.
- Solid understanding of end-to-end web app functionality (HTTP, APIs, data persistence, deployment).
- Experience with shared codebases (Git, meaningful commits).

Preferred:
- Familiarity with serverless/edge computing.
- Modern front-end framework (React, Vue, Svelte) and/or MCPs/APIs, data modeling, or systems design (back-end seat).
- AI-assisted development tools (Cursor, Windsurf, OpenCode).
- Prior sprint-based team experience.
- For UI seat: design systems, Figma, or strong interaction design sense.

Solve real problems with AI and code; mentorship + dedicated manager + 1:1s; real sprint work with production deliverables; access to Cloudflare intern cohort; a portfolio artifact (production-deployed code + shipped product demo).
