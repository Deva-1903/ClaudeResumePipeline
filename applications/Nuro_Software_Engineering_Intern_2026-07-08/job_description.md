Software Engineering Intern — Nuro

Nuro is a physical AI company developing Level 4 autonomous driving technology (the Nuro Driver universal autonomy platform) for robotaxis, logistics fleets, and personal vehicles. Founded 2016; raised over $2B from Uber, NVIDIA, Google, Softbank, Fidelity, T. Rowe Price, and others.

About the Role
As a software engineering intern, you will work closely with leading experts in machine learning, robotics, and software. Depending on your skill sets and interests, you will work on some or all of: Data Platform, Onboard Systems, ML Infrastructure, Simulation, or Technical Infrastructure teams.

About the Work
Data Platform: comprehensive management system for the AI Driver's data, labels, and metrics. Data annotation across 2D/3D perception, mapping, behavior trajectory, and language/text. Data ingestion and mining (heuristics, embedding search). Supports autonomy evaluation infrastructure with detailed introspection.
Onboard Systems: reliable, high-performance platform allowing autonomy teams to integrate autonomy software across self-driving platforms. Close collaboration with software, hardware, and systems/safety teams. Resolve onboard error and performance problems.
ML Infrastructure: accelerator to the ML-first autonomy strategy. Distributed training platform, ML compiler, model component libraries. Optimize on-cloud training and onboard inference.
Simulation: simulator for developing and testing autonomous driving in a virtual setting. Core simulator, sensor simulation, scenario generation, combining real-world data with synthetic techniques at scale.
Technical Infrastructure: generic compute platform for mission-critical workflows (data processing, simulation), storage management (hundreds of PB), cloud infrastructure as IaaC, engineering productivity (build, CI/CD).

About You
Current BS or MS candidate in Computer Science, Electrical Engineering, Robotics, or related field, graduating December 2026 or later.
Experience in one or more of: backend API design, applications development, large-scale distributed systems; data storage and processing systems; advanced algorithms using C++ and Python; machine learning, multithreading; x86 architecture; software performance tuning and optimization, robotics software frameworks, different compute modalities (CPU, GPU, FPGA), etc.
Strong problem solving and programming skills.
