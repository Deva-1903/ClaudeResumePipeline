Intern, AI Engineer — SES (Product and Innovation Engineering)

ROLE DESCRIPTION

The SES Product and Innovation Engineering team is building the next generation of intelligent, AI-powered products. We're looking for an AI Engineer Intern who can help architect and ship custom AI agents, Retrieval-Augmented Generation (RAG) pipelines, and full-stack AI applications grounded on proprietary knowledge bases and custom APIs. As a Java AI Engineer Intern, you'll design and build systems that connect LLMs to live data sources, internal APIs, and enterprise tooling, using Agile methodology, collaborating with engineers, product owners, and stakeholders. The ideal candidate understands how to build reliable, production-ready AI systems, not just proof-of-concept demos.

PRIMARY RESPONSIBILITIES
- Apply understanding of LLMs to design and build custom AI agents capable of reasoning, planning, and taking actions via tool use and API integrations.
- Architect and implement RAG pipelines (document ingestion, chunking, embedding generation, vector storage, semantic retrieval) grounded on internal knowledge bases and custom APIs.
- Build full-stack AI applications with a Java/Python backend (FastAPI/Flask) and a frontend UI (React or Next.js) that surfaces agent outputs and conversational interfaces.
- Integrate LLM agents with custom REST APIs using function calling / tool use patterns.
- Contribute to prompt engineering and context management (system prompts, few-shot, context window optimization).
- Collaborate to define agent behavior, memory patterns, and guardrails.
- Write clean, well-tested code, participate in code reviews, document implementations.
- Participate in Agile ceremonies (stand-ups, backlog refinement, sprint planning, retrospectives).
- Communicate effectively with team members and stakeholders.

COMPETENCIES
- Deep understanding of LLM concepts: prompt engineering, embeddings, function calling, RAG architecture.
- Proficiency in Python for AI pipelines, APIs, data workflows.
- Hands-on with LLM orchestration frameworks (LangChain, LlamaIndex, or equivalent).
- Architect end-to-end RAG with vector database integration (Pinecone, ChromaDB, AWS OpenSearch, pgvector).
- Strong REST API consumption skills.
- Familiarity with AWS services (S3, Lambda, Bedrock, OpenSearch).
- Clear communication skills.

- Exposure to an LLM orchestration framework (LangChain, LlamaIndex, or equivalent).
- Understanding of RAG architecture: chunking, embedding models, vector databases, retrieval strategies.
